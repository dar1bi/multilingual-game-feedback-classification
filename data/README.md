# Дані

Дані цього проєкту — внутрішні коментарі користувачів хмарного гейм-сервісу, залишені в момент
скасування підписки. Вони містять користувацький контент і є конфіденційною інформацією компанії,
тому **не публікуються в репозиторії**.

## Опис датасету

- **Джерело:** внутрішня база даних сервісу, записи типу `SUBSCRIPTION_DELETE`.
- **Обсяг:** 4 616 записів, 3 956 після очищення.
- **Структура:** службові поля (ідентифікатори, дата, тип події) та текстове поле у форматі JSON,
  у якому ключ `"other"` містить коментар користувача, а решта ключів — проставлені ним мітки
  технічних проблем.
- **Мови:** мультимовні коментарі, 70.6% англійською; далі португальська, французька, іспанська,
  українська, німецька та інші.
- **Цільові класи (6):** `ping_latency`, `frames_drop`, `unable_launch`, `mouse_keyboard_headset`,
  `game_bug`, `failed_save`.

Повний опис структури, статистика розподілів і візуалізації — у розділах 1–3 нотбука.

## Відтворення результатів

Для повторного виконання нотбука потрібен доступ до вихідного датасету. Файл розміщується в цій
теці, а шлях до нього задається змінною `DATA_PATH` на початку нотбука.

Без даних нотбук залишається повністю доступним для перегляду: усі виводи, графіки, таблиці
експериментів і результати моделей збережені безпосередньо у файлі нотбука.
